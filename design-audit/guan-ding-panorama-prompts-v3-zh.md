# 官窑、定窑背景提示词 V3｜放大细节强化版

日期：2026-08-06

## 为什么 V2 放大后缺少细节

- V2 把中央约 22% 设为安静区，球面相机放大后经常只截取到这一段低对比釉面。
- 官窑的大开片尺度过大、线色过浅，局部视场中只剩类似山形色块的宽阔明暗。
- 定窑的主体花纹集中在画面边缘，中央和中段存在过大的象牙白空白。
- 两张图的局部明暗对比偏低，再叠加运行时压暗和球面投影后，浅刻、细裂与釉面微纹理容易消失。

V3 不追求密集填满，而是建立“大结构 + 中尺度识别特征 + 细微釉面肌理”三层信息。以下两条提示词取代 V2 文档中的官窑和定窑提示词；不要把 V2、V3 叠加使用。

## 01｜官窑背景 V3

```text
使用场景：宋瓷手机交互界面中的南宋官窑球面窑境背景。最终画面会被映射到球面并以较窄视场放大观看，因此任何局部裁切都必须保留清楚的官窑材质特征。

生成一张 2:1 横向 equirectangular 等距柱状全景材质图，必须输出 4096 × 2048；如果工具只能输出较小尺寸，则最低不得低于 2048 × 1024。画面是近距离、近似正投影的南宋官窑厚釉陶瓷表面，不是房间、山水、地形、石板、墙壁或完整器物。

核心材质是成熟、厚润、乳浊的粉青釉。颜色以粉青、灰青、冷灰绿、月白和极少量暖褐胎影为主。釉层必须有真实厚度：高处呈温润粉青，微凹处略深，裂隙内部透出克制的灰褐胎色。釉面保持柔和半光泽，但不能被雾化、磨砂化或做成低对比灰墙。

建立三层可见细节：

第一层是 5–7 条中大型冷灰开片骨架，贯穿画面不同区域。每条开片必须有清楚但自然的深浅变化，宽度在 4096 像素母图中约为 3–8 像素，不能细到缩小后消失，也不能粗成山脊、沟壑或拼接板边缘。

第二层是分布在大开片附近的暖灰褐细开片。它们形成疏密不均的局部网状结构，每一组覆盖约全图宽度的 10%–18%，在左侧、中部和右侧都至少出现一组；不能只集中在画面边缘。细开片颜色要比釉面暗 12%–20%，清楚可辨但不使用纯黑、金色或发光描边。

第三层是全画面连续存在的釉面微起伏、细小气泡感和厚釉流动痕迹。它们必须清晰、均匀对焦，在没有大开片的区域也能提供细节，但不能变成粗砂、橘皮、针孔、粉末或烧成缺陷。

这是用于放大观看的全景材质。以任意约占全图宽度 28%–35% 的竖向裁切作为一个手机视场，在每一个这样的裁切中都必须同时看到：至少一条中大型开片、若干细开片、可识别的厚釉微起伏。禁止出现宽度超过全图 14% 的纯净空白区、无纹理渐变区或只有一整块颜色的区域。

中央窑火入口区域缩小为全图宽度约 12%–14%。该区域可以降低最粗开片的数量，但不能清空细节；必须保留一条较柔和的中型开片、少量细开片和釉面微起伏。窑火背后保持中低对比，窑火周围仍有足够官窑特征。

构图避免上一版类似重叠山峦、叶片或地形切面的巨大色块。大开片应是不规则、连续、具有陶瓷釉层深度的裂纹线，而不是宽阔平面之间的边界。左、右最外侧各约 8% 使用相近亮度、相近纹理密度，并让细开片在边缘自然延续，方便后续修复球面接缝。

采用低角度、方向明确的博物馆掠射光。光线从左上向右下缓慢经过，使开片一侧产生极细微的暗边，另一侧出现柔和釉面亮边。局部对比必须足以承受运行时约 35% 的压暗；暗部不能糊成一片，高光不能过曝。全画面均匀清晰，不使用景深、柔焦、雾气或边缘模糊。

最终效果必须一眼属于南宋官窑：厚润粉青釉、冷灰大开片、暖灰褐细开片、深胎暗示和庄重秩序同时存在。它不能仅靠灰绿色相区分，也不能与哥窑的强烈金丝铁线、汝窑的稀疏淡开片混淆。

禁止：完整器物、器沿、口沿、足部、紫色圆边、房间、天空、山峦、山水、地形、石板拼接、叶片重叠、火焰、烟雾、门户、中心洞口、文字、Logo、水印、纯黑粗裂缝、金色裂纹、发光描边、满屏均匀龟裂、宽阔空白、低对比灰雾、普通水泥、混凝土、石膏、冰面、玻璃、塑料、粗砂、橘皮、针孔、过曝高光、强景深、局部虚焦、明显左右接缝。
```

## 02｜定窑背景 V3

```text
使用场景：宋瓷手机交互界面中的北宋定窑球面窑境背景。最终画面会被映射到球面并以较窄视场放大观看，因此花纹不能只停留在全景边缘，任何局部裁切都必须保留可辨认的定窑浅刻或印花细节。

生成一张 2:1 横向 equirectangular 等距柱状全景材质图，必须输出 4096 × 2048；如果工具只能输出较小尺寸，则最低不得低于 2048 × 1024。画面是近距离、近似正投影的北宋定窑象牙白釉刻花与印花陶瓷表面，不是白墙、纸张、织物、石膏板、欧式浮雕或完整器物。

核心材质是“白如凝脂但细节充足”的定窑象牙白薄釉。颜色包含温暖象牙白、乳白、米白、浅杏灰和极少量冷白高光。釉层紧贴细白胎，致密、干净、成熟，具有柔和半光泽和细微胎釉深度。背景不能是大面积纯白或均匀奶油色；即使在负空间中，也必须持续存在非常细的釉面波纹、拉坯痕、微小色温变化和胎釉颗粒。

建立三层可见细节：

第一层是 3–4 组中大型、不完整的缠枝牡丹、莲瓣或折枝花叶。每组纹样宽度约占全图 18%–28%，分别分布在左侧、中左、中右和右侧，不能全部挤在四角。花头与叶片从画面边缘或相邻纹样中自然进入，但至少有两组纹样必须穿过全景中段，使放大后的中央视场也能看到定窑装饰。

第二层是连接主体纹样的长卷枝、细叶和浅印花弧线。它们以疏朗、连续的曲线穿过负空间，线条在 4096 像素母图中具有约 4–10 像素的可见明暗宽度。曲线不能细到缩小后消失，也不能像白色描边、蕾丝或浮在表面的奶油装饰。

第三层是全画面连续存在的薄釉微波纹、细胎颗粒、浅刻刀痕和极淡的暖冷色差。即使没有花头的区域，也必须保留这些微细节，避免放大后成为空白白墙。所有细节都应完成烧成、边缘圆润而清楚，不能表现为粉质、湿泥或粗糙石膏。

这是用于放大观看的全景材质。以任意约占全图宽度 28%–35% 的竖向裁切作为一个手机视场，在每一个这样的裁切中都必须看到：至少一段清楚的卷枝或莲瓣轮廓、若干浅刻或印花细节、可辨认的薄釉微纹理。禁止出现宽度超过全图 12% 的纯白空白区、无纹理渐变区或只剩柔焦奶油色的区域。

中央窑火入口区域缩小为全图宽度约 12%–14%。这里不能放置完整大花头，以免与窑火争夺焦点，但必须让一条长卷枝、两三片浅叶或一段莲瓣轮廓从窑火后方经过。纹样保持中低对比，却必须在运行时压暗后仍可看见。

浅刻和印花通过真实侧光显形。凹处使用比基底暗 10%–18% 的暖灰米色阴影，转折高处使用比基底亮 6%–12% 的柔和象牙白高光。局部对比要比上一版更明确，但禁止纯白描边、金线、黑线或厚重阴影。牡丹花瓣、莲瓣和叶片边缘必须利落、连续、比例匀称，不能软塌或糊成一团。

构图保持宋代定窑的文雅与疏朗，但“疏朗”不等于空白。较大的牡丹可位于左下，中型莲瓣或折枝花叶位于中右和右上，长卷枝横跨中段并连接各区域。左、右最外侧各约 8% 使用相近亮度与相近纹理密度，并让卷枝或浅印花在边缘自然被裁切，方便后续修复球面接缝。

采用温暖、方向明确、低角度的博物馆侧光。全画面均匀清晰，不使用景深、柔焦、雾化或边缘模糊。纹样在完整全景中保持优雅，在放大局部中仍能看到浅刻深度、花叶结构与釉面细节。最终效果必须不依赖文字也能辨认出定窑，而不是普通象牙白背景。

禁止：完整器物、盘碗、器沿、孩童人物实体、雕塑、房间、墙面、纸张、织物、蕾丝、皮革、石膏、水泥、欧式浮雕、巴洛克、洛可可、厚重雕花、贴花、奶油糖霜、纯白描边、金线、彩绘、黑色裂纹、密集龟裂、火焰、烟雾、门户、中心洞口、文字、Logo、水印、大面积空白、柔焦奶油渐变、低对比雾化、强镜面反光、过曝、塑料、机械重复纹样、局部虚焦、明显左右接缝。
```

## 生成与验收方法

1. 官窑、定窑分开生成，每次只使用对应 V3 提示词。
2. 每窑生成 2–4 张母图，先不要求无缝；优先检查放大细节和任意局部裁切。
3. 把候选图分别裁出左、中、右三个约占原图宽度 30% 的局部；三个裁切都能辨认窑口才算通过。
4. 将候选图缩小到手机显示尺寸并压暗约 35%；中型纹样、开片和釉面微纹理仍需可见。
5. 母图通过后，再使用 `five-kiln-background-redesign-v2-zh.md` 中的第二阶段接缝修复提示词，只修左右各约 8%。
