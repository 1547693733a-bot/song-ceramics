# 流畅度与 UI 完整度升级

## 本轮范围

保留八窑已确认的画面、视频与环境声，不改变火焰颜色、亮度或对比度，不修改受保护的设备模拟与手势运行时。本轮没有覆盖线上发布版本。

## 已实施

- 入口每帧视角与视差更新改为 ref/CSS 属性直写，避免拖动时整棵 React 界面树重复渲染；保留观察纹理、到边界才换窑的规则。
- 统一两套三幕切换控制器：手指停留时不自动吸附，松手后平滑归位，支持中途重新接管和首尾循环。
- 修正 RAF 时间戳误作页面位置；修正交叠图层在半透明中点露出深色背景的问题。
- 隐藏非贡献场景图层，临时而非永久使用合成提升；原生视频循环不再运行无效的逐帧截断检查，未激活的环境声不提前加载。
- 火焰 WebGL 使用缓存尺寸、较高浮点精度与隐藏页面暂停；不支持所需精度时保留原图回退，不使用新的色彩增强效果。
- 统一返回、声境、知识详情控制；知识详情使用标准底部面板，保留史实依据、场景说明和来源链接，修复标题与正文重叠，补全阅读色与键盘焦点。
- 视频慢加载、自动播放被阻止或失败时提供延迟提示与重试；兼容已有双视频接续，不将后台副本暂停误判为故障。
- 浏览器复测发现磁州窑第三幕在首次加载时将尚未可用的视频时长固定为 NaN，导致播放到 8 秒停止。改为元数据就绪后计算接续点，并确保媒体结束时完成交接；保留已有向前接续方式。
- 页面标题改为“宋瓷 · 八窑”。

## 验证

- `node --test tests/scene-navigation.test.mjs`：12 项通过，覆盖两套故事的循环、手指停留、中点混合、打断、窗口调整、键盘及减少动态偏好。
- `node --test tests/scene-playback-status.test.mjs`：4 项通过，覆盖正常播放、双视频接续、加载/阻止/错误区分和后台/卸载清理。
- `npm run test:sites`：4 项通过。
- `node --test tests/cizhou-video-loop.test.mjs`：1 项通过，覆盖首次未加载元数据与末帧接续。
- `npm run build`：通过，含 TypeScript 与 28 个受保护运行时文件完整性检查。现有构建脚本仅从输出包剔除不用的资源，原始素材未删除。
- 本地浏览器验证入口、小幅拖动、从火焰区域拖动换窑、磁州窑入场与三幕拖动、龙泉窑通用界面第一幕反向循环至第三幕、两套科普面板展开/关闭与排版；其他设备的实测帧率、微信 WebView 与弱网播放仍需要真机复测。

## 后续边界

未声称所有手机稳定 60 FPS。当前主 JavaScript 包仍有大于 500 kB 的构建告警，后续可独立拆分 Three.js/入场模块；本轮未为消除告警改动受保护的构建配置。新旧线上版本需在获准发布后再进行同机对比。
