# 磁州窑三级界面「梅瓶一镜到底」总规划 V1

## 1. 方向结论

三级界面不再是三张“器物卡片”，而改为一条连续叙事：

`窑场出器 → 北地流通 → 酒肆入席`

同一只白地黑花梅瓶从头到尾保持在同一视觉位置，作为连续的叙事锚点；用户左右滑动时，变化的是它所处的空间、环境光、声音和知识视角。这样既承接二级界面烧成后的梅瓶拉远动画，也能逐步从“烧成”进入“磁州窑如何成为北方民间生活的一部分”。

推荐总题为：`一瓶见磁州`

这不是把三个生活场景简单排成轮播，而是借同一件器物依次解释磁州窑的三层特性：

1. 材料与工艺：粗胎如何通过化妆土与黑彩实现“粗瓷细作”。
2. 民窑与流通：磁州窑如何形成面向北方生活的大规模民窑体系。
3. 功用与生活：梅瓶为什么是盛酒器，民间绘画如何真正进入日用器。

## 2. 为什么需要重构现有三章

现有三张素材分别是梅瓶、玉壶春瓶和瓷枕，但三张都采用低照度室内、暖灯、深褐木案，导致视觉上只是“换了器物”，没有真正换场景。

如果采用“同一梅瓶一镜到底”，原来的 `刀笔生花` 和 `瓷上人间` 不能原样保留：剔划花玉壶春瓶和“张家造”瓷枕的知识证据不在当前梅瓶上，强行把这些热点放到梅瓶上会造成史实与视觉证据错位。

因此应把知识结构从“三件器物代表三种特性”调整为“同一件器物串起磁州窑的三个层面”。玉壶春瓶与瓷枕资料可以保留在后续扩展的“更多器物”详情页，不在这一镜到底的主链路中承担第一层叙事。

## 3. 三幕场景分镜

### 第一幕：窑场初明｜白地为纸

- 叙事位置：承接二级界面烧成与梅瓶拉远，是“出窑后的第一口空气”。
- 场景：清晨或阴天的北方窑场院落，窑壁、匣钵、素坯与淡淡窑烟退入柔焦背景；不是仍在燃烧的火窑，也不是纯黑空间。
- 主色：冷灰蓝、灰白陶土、少量温暖窑灰。
- 明度：三幕中最清透，明显打破当前三个场景都昏暗的问题。
- 核心知识：粗胎、白色化妆土、含铁黑彩、透明釉与高温烧成。
- 页面短句：`粗胎着白，黑彩成画。`
- 两个知识点：
  1. `看白地`：化妆土如何实现“粗瓷细作”。
  2. `看黑彩`：含铁颜料如何在白地上形成水墨般对比。
- 声音：窑体冷却轻响、远处搬匣钵、风过院落、偶发瓷器轻碰；避免持续烈火声。

### 第二幕：北地成市｜器行民间

- 叙事位置：器物离开窑场，进入交换、运输和普通人的生活网络。
- 场景：日间北方市集或临近水陆转运的陶瓷货摊，布棚、木箱、车轮和远处人流以大色块呈现；不堆满摊位细节，不做古装影视街景。
- 主色：日晒赭石、克制靛青、灰绿色布棚、少量暗朱红。
- 明度：中高明度，色彩最丰富，是三幕的视觉转折点。
- 核心知识：磁州窑是北方重要民窑，器类丰富、坚固耐用，并向多地传播形成磁州窑体系。
- 页面短句：`一窑成系，器走北方。`
- 两个知识点：
  1. `看民窑`：面向日常使用而非只为陈设的生产逻辑。
  2. `看流通`：瓶、罐、碗、盆、瓷枕等器类如何进入更广阔的生活网络。
- 声音：车轮、脚步、布棚风声、远处叫卖和瓷器装箱声；人声作为背景层，不做清晰对白。

### 第三幕：酒肆入席｜器入人间

- 叙事位置：同一梅瓶到达最终使用现场，完成“从窑火到生活”的闭环。
- 场景：宋金北方酒肆的傍晚或入夜时分，酒碗、木案、店客轮廓与灯影说明功能；空间应比现有版本更有层次和暖色，但不能重新陷入大片纯黑。
- 主色：琥珀、克制朱砂、墨黑、米白。
- 明度：局部暖亮，中部和人物柔焦，不以黑暗作为唯一高级感来源。
- 核心知识：梅瓶的小口、短颈、丰肩与修腹适合盛酒；磁州窑把花鸟、人物、文字等民间题材带入日用瓷。
- 页面短句：`瓶中有酒，瓷上有人间。`
- 两个知识点：
  1. `看器形`：梅瓶作为宋代盛酒器的形制与功用。
  2. `看花纹`：民间喜闻乐见的题材和自由明快的笔意。
- 声音：斟酒、酒碗轻碰、近处低语、远处店家招呼；保持层次但不做持续嘈杂噪声墙。

## 4. 一镜到底的实现方式

### 推荐：2.5D 分层场景，而不是三张完整成图横向轮播

始终只渲染一只梅瓶主体，背景与环境光独立切换：

1. `背景层`：三张无梅瓶、无文字、无 UI 的场景底图。
2. `空间层`：每幕少量前景遮挡、桌面接触面、烟尘或布帘。
3. `器物层`：同一张透明背景梅瓶母版，全程保持比例与锚点一致。
4. `光影层`：每幕单独的瓶身环境光、落影和接触阴影蒙版。
5. `知识层`：标题、两个热点与详情；只在场景稳定后出现。
6. `声音层`：三段可无缝循环的环境声，随场景进度交叉淡化。

这种结构比生成三张带瓶子的完整图片更适合“一镜到底”：如果每张图都重新生成梅瓶，器形、纹样、尺寸和透视会在切换时跳变，连续性会被破坏。

### 滑动表现

- 用户拖动时，梅瓶只产生极轻的 2–4px 视差或完全固定，不跟随卡片离开屏幕。
- 旧背景缓慢向一侧偏移约 6%–10% 并降低明度，新背景从另一侧以不同景深进入，同时交叉淡化。
- 瓶身环境光与接触阴影跟随背景渐变，让梅瓶看起来真正处于新空间，而不是贴在背景上。
- 当前文字先淡出，下一幕文字在过渡 65% 后淡入；热点只在归位后延迟约 300ms 出现。
- 松手后以约 0.9–1.2 秒缓慢收束到相邻场景；一次手势最多切换一幕，避免快速滑过完整链路。
- 环境声在 0.8–1.2 秒内交叉淡化，不能突然停播或重新从零开始。
- 不恢复底部数字导航；返回与声音继续保留纯图标。

## 5. 新素材清单

### A. 必须新增

| 素材 | 数量 | 建议规格 | 说明 |
| --- | ---: | --- | --- |
| 梅瓶透明母版 | 1 | 透明 PNG，主体高度至少 2048px | 从已经认可的梅瓶素材中编辑分离，不能重新凭空生成另一只瓶 |
| 梅瓶主体蒙版 | 1 | 与母版同尺寸的灰度 PNG | 用于不同场景的环境光和色温变化 |
| 无器物场景背景 | 3 | 1179×2556，PNG/WebP | 窑场清晨、市集日间、酒肆傍晚；全部无瓶、无字、无 UI |
| 接触阴影/前景遮挡 | 3 组 | 1179×2556 透明 PNG | 让固定梅瓶落在不同桌面或台面上，不显得悬浮 |
| 环境声循环 | 3 | 20–35 秒无缝循环 | 窑场、市集、酒肆；保留 WAV 母版，运行时可转 OGG |

### B. 可选增强

- 三张瓶身光照通道：冷晨光、日晒暖光、灯火侧光。
- 市集远景的极轻布棚摆动层，酒肆灯焰与人物轮廓层；只做小幅循环，不做完整视频。
- 每幕一张史料详情图或馆藏局部图，放在热点详情中，不直接占据主场景。

## 6. 素材生产顺序

1. 先从当前认可的梅瓶图中提取透明梅瓶母版并确认器形、纹样和正面朝向。
2. 用母版确定手机画面中的固定锚点、尺寸和顶部文字安全区。
3. 再生成三张“无器物背景”，每张都以同一锚点预留桌面和负空间。
4. 为每张背景补接触阴影、前景遮挡和瓶身环境光。
5. 三幕并排检查色相、明度和空间差异，通过后再制作环境声。
6. 素材通过后才进入程序接入，避免一边改交互一边反复换图。

## 7. 图像生成统一约束

所有场景提示词必须包含：

> 避免细节堆砌。画面风格要求：柔焦边缘，克制的细节表达，大色块优先，材质统一干净，避免堆砌细碎纹理，整体通透高级。

共同限制：

- 竖版 1179×2556，移动端沉浸式展览画面。
- 不生成梅瓶、器物主体、文字、印章、界面、现代物件或博物馆展柜。
- 三幕不能共享同一套深褐黑背景与右上暖灯构图。
- 人物只作为柔焦环境关系，不出现清晰脸部、戏剧化表演或影视剧照质感。
- 保留左上文字安全区和梅瓶固定锚点周围的干净轮廓。
- 不使用高饱和霓虹、过度金色、密集纹理、满画面道具或强烈 HDR。

### 三幕差异约束

- 窑场：冷灰蓝和陶土白，大面积自然天光，不用橙红火焰主导。
- 市集：赭石、靛青、灰绿和暗朱红，明亮开放，不做暗室。
- 酒肆：琥珀和克制朱砂，有人物与酒碗关系，但保留中间调，不做纯黑夜景。

## 8. 程序落地拆分

### 批次 1：内容与素材骨架

- 重写 `cizhouTraits` 为同一梅瓶的三幕知识结构。
- 保留现有第一幕梅瓶资料与权威来源。
- 将玉壶春瓶和瓷枕内容移出主场景数据，暂存为后续“更多器物”扩展内容。
- 建立场景、热点、环境声、复原声明和史料来源的统一数据结构。

### 批次 2：一镜到底渲染

- 把当前 300% 宽的三张完整场景，改为固定梅瓶＋三组背景层。
- 将横向手势进度映射到背景视差、透明度、瓶身光照、文字和声音。
- 保留现有 Carousel 的手势仲裁，不修改受保护的移动端运行时。

### 批次 3：知识交互

- 每幕只保留两个首层热点。
- 热点详情明确区分“文物事实”和“情境复原”。
- 史料来源放在详情底部，不在主画面堆叠说明。

### 批次 4：调校与验收

- iPhone 与 Pixel 10 分别检查顶部安全区、热点可点范围和底部声音按钮。
- 实机比例下验证连续拖动、慢速拖动、快速甩动和反向中止。
- 检查音频交叉淡化、页面隐藏后暂停以及低动态模式降级。

## 9. 验收标准

1. 不看文字也能在一秒内分辨三幕：冷清窑场、明亮市集、暖色酒肆。
2. 梅瓶在三个场景中的器形、纹样、比例和主要锚点不发生跳变。
3. 滑动时首先感受到“环境在梅瓶周围变化”，而不是三张卡片横移。
4. 三幕知识分别回答“怎么做出来、怎么进入民间、在生活中怎么用”。
5. 每幕最多两个首层热点，主画面无多余导航与说明文字。
6. 三组声音可以连续循环，切换无爆音、无突然静音。
7. 所有文物事实有来源，艺术复原内容明确标注为情境复原。

## 11. 下一步执行门槛

本规划确认后，下一步不是直接改程序，而是先完成一张三幕并排的视觉样稿：同一梅瓶固定在画面中，分别叠加窑场、市集和酒肆背景。只有当三幕色调差异、梅瓶连续性和文字安全区同时通过后，才进入正式素材生产与程序接入。
