# 「器之初·定心开器」中文素材生成提示词

这套提示词用于项目首屏动画素材。请按照素材类别分别生成，不要让模型一次生成整段动画。

## 使用规则

1. 泥团、左手、右手、陶轮湿光和转场纹理必须分开生成。
2. 后续关键帧都使用上一帧作为参考，只改变动作阶段，不改变机位、比例、光线和材质。
3. 透明素材使用纯绿色背景 `#00ff00`，生成后再本地去色键；不要生成棋盘格透明背景。
4. 生成结果不得包含文字、标志、水印、火焰、完整梅瓶或额外器物。

## 全局风格锁定词

把下面这段附加到每个提示词末尾：

```text
宋代北方陶瓷作坊的气质，克制的材质写实感，温暖的深褐色泥土，细微湿润光泽，颗粒状泥料表面，左上方柔和定向光，纯黑负空间，安静、含蓄、沉思的氛围，适合手机竖屏互动原型，主体居中，手部解剖结构自然，保留手作的不规则细节，不要幻想化装饰，不出现现代工作室设备，不出现文字、标志或水印。
```

## 1. 未定心泥团｜锚点帧

用途：替代当前椭圆形悬浮泥块，作为动画第一帧。建议将项目已有 `origin-clay-v1.png` 作为参考图。

```text
用途：精确对象编辑
素材类型：手机端陶艺互动动画的泥团关键帧
输入图片：图片1是项目现有真实泥团素材，用于保持泥料纹理和身份；图片2是宋代磁州窑梅瓶轮廓，仅用于理解未来器形比例
主要要求：只改变泥团姿态和承托关系。把不规则、悬浮的泥块变成一团放在隐形陶轮中心的低矮泥丘。保留图片1中的真实深褐色颗粒泥料、孔洞、细小凹点、干湿变化和柔和自然高光。
场景：纯黑负空间；泥团底部只出现一道非常暗的湿润椭圆反光，不显示机器
主体：一团尚未成形的泥，位于画面中心，底部略宽，顶部略圆，具有未来制作梅瓶所需的泥量
风格：克制的写实泥料微距摄影，不要插画感
构图：正方形素材，泥团居中，四周保留大量黑色边距，完整轮廓可见
光线：一道很暗的湿润高光，不要戏剧化发光
材质：北方粗质陶土的颗粒感、细小孔隙和局部湿润表面
约束：保持原始泥料身份和纹理；不出现完整器形；不出现手；不出现装饰、文字和水印
```

```text

输入图片：图片1是“未定心泥团”关键帧，用于保持机位、比例和材质

场景：纯黑负空间；保留同一条极暗的湿润椭圆轮盘反光
主体：一根居中的未完成泥柱，没有瓶颈、瓶口、肩部和内腔
风格：克制的写实泥料微距摄影
构图：与图片1使用完全相同的裁切、比例、机位、光线和主体中心
```

## 3. 开孔泥团｜核心锚点帧

用途：表现器物第一次出现内部空间，必须是“真正的孔”，不能只是表面凹痕。

```text
用途：精确对象编辑
素材类型：泥团开孔动画关键帧
输入图片：图片1是“定心泥团”关键帧，用于保持身份、机位和外轮廓
主要要求：只改变泥团顶部中心。表现陶工用拇指从顶部垂直按入定心泥团，形成一个干净、圆形、真实进入泥体内部的开孔。孔内应出现湿润的深色内壁，孔口周围保持均匀的厚度。外部泥团仍然低矮、未完成。
场景：纯黑负空间，保留同一条隐约陶轮反光
主体：一个具有初始内腔的泥团，不是完整器物
风格：克制、写实、具有触感的泥料微距摄影
构图：与图片1完全相同；开孔位于垂直轴线上，在手机尺寸下清晰可辨
光线：孔口边缘有柔和湿润高光，孔内保持深暗，不要人工发光
材质：真实泥粒、湿润指压边缘、细微螺旋拉坯纹
约束：开孔代表器物的第一个内部空间；保持外部轮廓；此独立泥团素材中不出现手
避免：浅表指印，陨石坑，贯穿底部的洞，宽口碗，完整花瓶，釉面，装饰，火焰，文字，水印
```

## 10. 统一迭代修正词

### 保持前后帧一致，只改变动作

```text
保持图片1完全相同的机位、裁切、主体中心、比例、泥料纹理、光线方向、色彩和轮廓。只把动作阶段从“上一阶段”改为“下一阶段”。不要新增物体，不要改变风格，不要添加文字和水印。
```

### 修正绿色边缘溢色

```text
保持手部解剖结构、姿态、比例和构图完全不变。只清除手部边缘和袖口边缘的绿色溢色。背景仍必须是完全均匀的纯 #00ff00，边缘不能有绿色光晕、阴影或重新设计。
```

### 防止泥团被生成成完整器物

```text
把成形阶段限制在尚未完成的早期泥坯状态。开孔保持浅而清晰，器壁保持厚实，只显示最初的起壁。不要出现瓶颈、瓶肩、圈足、釉面、装饰和完整梅瓶轮廓。
```

## 推荐生成顺序

1. 用项目已有 `origin-clay-v1.png` 作为参考，生成 1–4 号泥团关键帧。
2. 生成 5–6 号左右手开放姿态，再分别编辑出进入、扶稳、开孔和退出帧。
3. 用 7 号姿态参考图检查两只手的触点和相对位置。
4. 最后生成 8–9 号陶轮湿光和内腔转场纹理。
5. 磁州窑全景继续使用项目现有素材，不重新生成。
