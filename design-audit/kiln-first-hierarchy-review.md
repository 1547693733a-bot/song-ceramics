# 首页叙事层级评审：由“器物轮播”改为“八窑漫游”

## 评审范围

- 页面：当前手机端首页默认状态
- 证据截图：`01-current-home.png`
- 本轮目标：只判断叙事层级，不修改代码

## 核心结论

用户的判断成立。当前 Demo 的视觉主语、交互主语和文案主语都是“器物”：

- 完整器物位于画面正中，是最亮、最清晰、最可点击的对象。
- 巨大虚影仍然来自器物轮廓，因此它放大的是“器形”，而非窑口特征。
- 页面使用“八窑 · 八器”“左右滑动探索八件宋瓷”“上一件器物”“八件器物位置”等表达。
- 不同页面更换的是器物，空间、光色、切片和动效的基本规则没有随窑口发生本质变化。

所以用户获得的心智模型是“看八件宋瓷”，不是“进入八个窑口”。

## 建议的叙事顺序

“窑口优先”不等于先弹出一页文字介绍，而应当是：

1. 先感知窑口：空间、火候、釉色、纹理、声音或运动规律先发生变化。
2. 再辨认代表器物：器物从该窑口特有的环境中逐渐显形，成为可点击锚点。
3. 点击后进入器物知识：器形、釉色、工艺、历史与细节放大。

一句话概括：**先进入一种窑的世界，再遇见这件器物。**

## 首页单元的重新定义

当前一个横向页面是“一件器物卡片”；建议改为“一个窑口场域”。

| 层级 | 当前 | 建议 |
| --- | --- | --- |
| 第一视觉 | 完整器物 | 窑口特征形成的空间与材料场 |
| 第二视觉 | 器物巨大虚影 | 从场域中显形的代表器物 |
| 主标题 | 器物名 | 窑口名 |
| 辅助信息 | 抒情短句 | 窑口特征短句 + 代表器物名 |
| 滑动行为 | 换一件器物 | 进入另一个窑口场域 |
| 点击行为 | 聚焦器物 | 从窑口层进入代表器物层 |

## 建议保留与修改的部分

### 可以保留

- 左右循环滑动，仍然支持任意顺序的自由探索。
- 八个扇片/门片形成的空间结构。
- 完整器物作为稳定的点击目标。
- 黑、窑红、暗金的总体基调。

### 需要修改

- 巨大虚影不再固定等于器物轮廓，而应成为“窑口特征场”：可以来自釉面纹理、窑变轨迹、刻划节奏、火焰与落灰等视觉材料。
- 页面切换时，先让整个环境发生变化，器物稍后显形；不要让器物与背景同时平移。
- 窑口名成为最明确的一级信息，器物名降为二级。
- 八个页面不能只更换 PNG；每个窑口至少应有一套独立的色、材质、光、运动规则。

## 建议的单页时间节奏

- 0–0.8 秒：滑动进入，原窑口场域消退，新窑口的材质与光开始接管画面。
- 0.8–1.5 秒：窑口名与一条极短的特征文字出现。
- 1.2–2.2 秒：代表器物从暗处、纹理或门片之间显形并悬停。
- 稳定后：器物可以点击，进入器物层。

这会保留意识流体验，同时让“窑口—器物”的因果关系被用户感受到。

## 不建议的极端方案

不建议把器物完全藏到第二页。那会失去首页最清楚的触摸目标，也削弱用户对内容的直觉理解。更好的方式是降低器物在首屏的支配性，而不是取消器物：器物仍在，但它像从窑口气候中被孕育出来。

## 风险提示

- 不能只靠颜色区分八窑，否则既容易同质化，也不利于色觉差异用户。
- 每个窑口至少需要“颜色之外”的第二识别线索，例如纹理、运动节奏、空间结构或器物出现方式。
- 若用户开启减少动态效果，应保留窑口名、纹理和构图差异，避免核心信息只存在于动画中。

## 下一步建议

先选择一个资料最完整的窑口，做一张“窑口优先”的静态对照效果图；确认层级成立后，再扩展到八窑并重构动效。
