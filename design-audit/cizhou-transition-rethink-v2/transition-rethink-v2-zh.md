# 磁州窑三级界面：转场重构方案 V2

## 结论

当前问题不是“再调一点色温或位置”可以解决，而是合成逻辑与转场模型都不成立：梅瓶使用一个全局固定锚点覆盖在三张透视、承托面高度都不同的背景上；同时整个背景卡片跟随手指横向离场，所以用户必然把它理解成“换图片”。

本轮不继续微调现有方案。推荐改为 **固定镜位的镜内换景**：手势只控制变景进度，画面本身不横向离开屏幕。梅瓶保持同一件、同一轮廓、同一接触点；环境、承托面材质、光线、声音与知识层在同一个镜头中连续溶变。

## 当前证据

- 第一幕：梅瓶底部没有明确承托面，环境尺度和明暗都把它读成悬浮贴图。见 `03-current-kiln-yard.png`。
- 第二幕：木板的透视与梅瓶底部接触点不一致，瓶身压在板堆前缘而不是落在板面上。见 `02-current-market.png`。
- 第三幕：桌面接触关系相对成立，因此也是新素材构图的透视参考。见 `01-current-tavern.png`。
- 交互：三张 100vw 卡片完整横移，边界和位移幅度过强；这属于图库语法，不属于空间转换语法。

## 新的统一空间规则

三幕在出图前必须锁定同一套摄影参数：

- 镜位不变：约 50mm 等效镜头，视平线约在画面 42%。
- 梅瓶不变：瓶底接触点固定在画面 `x=64% / y=84%` 左右，轮廓尺寸不变。
- 承托面不变形：三幕的承托面上沿、消失点、倾角完全一致；只允许材质由窑场石案、市场木案、酒肆桌案变化。
- 接触关系进入素材：每幕单独提供真实的接触阴影和前景遮挡层，不再用通用 CSS 椭圆阴影补救。
- 留出知识区：左上文字与右侧瓶体之间保持稳定负空间，不让背景主体穿过标题。

## 转场语法：不是横移，而是“场景在镜头内发生变化”

### 手势进度 0%—20%

- 梅瓶与瓶底接触点完全锁定。
- 标题、热点先淡出。
- 当前环境只产生 8—12px 的微弱景深位移，不能跟手平移一整屏。

### 手势进度 20%—70%

- 当前背景与下一背景在原位交叉溶变。
- 使用有叙事因果的近景遮挡物掩护空间变化：
  - 窑场 → 市场：窑烟逐渐变成日光中的尘雾，近景车布或人影短暂掠过。
  - 市场 → 酒肆：市棚布影从镜头前经过，布影落下后成为酒肆门帘与室内暗部。
- 承托面保持同一几何，只溶变材质；梅瓶的冷暖与明暗在这个阶段连续插值。
- 两套环境声在 25%—85% 区间交叉淡化，不等到翻页完成后才突然换声。

### 手势进度 70%—100%

- 下一场景由轻微柔焦恢复清晰，景深位移归零。
- 新接触阴影收稳，确认器物“落地”。
- 画面稳定约 180—240ms 后，再出现下一幕标题与热点。

### 松手规则

- 位移只作为时间轴输入，不直接显示为页面位移。
- 超过约 28% 或具有明确方向速度时，继续完成到下一幕；否则柔和回退。
- 完成时间约 0.85—1.1 秒，回退约 0.5—0.65 秒。
- 往回滑动时严格反演同一时间轴，不能使用另一套动画。

## 素材重做清单

1. 三张对齐的无瓶背景，使用同一镜位、同一视平线、同一承托面几何。
2. 三张透明前景承托层：石案 / 木案 / 桌案，几何完全一致。
3. 三张透明接触阴影与前景遮挡层，必须贴合相同瓶底。
4. 两组透明转场遮挡素材：窑烟—日尘、棚布影—门帘影。
5. 继续使用同一个透明梅瓶母版；不重新生成瓶体，避免器形和纹样漂移。

所有新素材继续遵守：避免细节堆砌。柔焦边缘，克制的细节表达，大色块优先，材质统一干净，避免堆砌细碎纹理，整体通透高级。

## 程序落地结构

- 继续保留受保护的 `Carousel` 作为手势与惯性控制器，但它只充当透明的“手势轨道”。
- 三个场景改为堆叠在同一个 viewport 内，不再把可见背景放进三张横移卡片。
- 根据 `scrollLeft / viewportWidth` 得到连续场景进度，驱动背景、承托层、遮挡层、瓶体光照和音量。
- React 状态只在转场收稳后提交标题、热点与语义状态；逐帧视觉插值使用 CSS 变量或 GSAP setter，避免滚动时反复渲染。
- 删除当前通用瓶底椭圆阴影和整屏背景横移；热点在运动期间关闭，收稳后恢复。

## 验收标准

- 任意中间帧都看不到完整图片边缘或下一张图片从屏幕外进入。
- 三幕梅瓶底部的接触点像素位置一致，且都与承托面成立。
- 在关闭文字后，仅凭运动也能理解为同一件器物从窑场进入市场、再进入酒肆。
- 转场中瓶体轮廓不缩放、不漂移、不换形，只改变环境反光。
- 第一幕不再悬浮，第二幕不再压在木板前缘，第三幕继续保持桌面落位的可信度。

## 执行顺序

1. 先做同镜位的三幕灰盒构图，只验证瓶底与承托面。
2. 灰盒通过后生产正式背景、承托层、接触阴影和两组遮挡素材。
3. 再改为堆叠场景时间轴，并接入声音连续交叉淡化。
4. 最后恢复知识文案与热点，做 iPhone / Pixel 两端验收。
