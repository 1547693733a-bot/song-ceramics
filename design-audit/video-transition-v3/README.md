# “胎土化墨”视频生成素材包

本目录用于生成首页“顶视开孔泥坯 → 孔内推进 → 胎土化为磁州黑彩 → 磁州窑界面”的连续过渡视频。

## 参考素材

1. `01-glb-top-start-reference.png`
   - 当前运行中 GLB 的准确顶视构图。
   - 生成时作为首帧与构图参考。
   - 只使用手机屏幕中的黑底泥坯；不要生成手机外框、设备选择器或白色页面。

2. `02-cavity-style-reference.webp`
   - 孔内陶土旋纹与“胎土化墨”的中段风格参考。
   - 只参考材质、旋纹和中心透视；不要把整张静态图当作突然出现的新画面。

3. `03-cizhou-end-reference.png`
   - 磁州窑黑彩、米白胎地、牡丹和卷草笔触的终态材质参考。
   - 这是 2:1 全景纹理，只作为风格和纹样参考，不应直接作为视频终帧拉伸使用。

4. `04-cizhou-screen-end-alignment.png`
   - 当前二级界面的构图、亮度和终态对齐参考。
   - 仅用于判断视频结束时的亮度与纹样密度；不得把文字、火焰、手机外框或状态栏生成进视频。

## 使用顺序

- 支持首帧输入的模型：上传 `01` 作为首帧，同时上传 `02`、`03` 作为风格参考。
- 支持多参考图但不区分角色的模型：在提示词中明确写出每张图片的角色。
- 支持首尾帧的模型：首帧使用 `01`；终帧应由 `03` 的磁州纹样生成一个无 UI 的正视方形画面后再使用，不要直接使用 `04`。
- 推荐先生成 3–4 秒、24 或 30fps 的镜头，保留短暂首尾稳定帧，再剪辑加速为网页使用的 1.2–1.5 秒版本。

## 输出要求

- 方形母版：`1024 × 1024` 或 `768 × 768`。
- 网页版本：H.264 MP4，720 × 720，30fps，无音频，`faststart`，建议控制在 1.5MB 内。
- 必须保持孔心固定在画面 `50% / 50%`。
- 全程为一个连续镜头，不得切镜、闪白、黑闪或出现第二个圆盘。

## 文件

- `VIDEO_PROMPT_ZH.txt`：中文主提示词。
- `VIDEO_PROMPT_EN.txt`：英文主提示词。
- `NEGATIVE_PROMPT.txt`：中英文负面约束。
- `STORYBOARD_AND_SETTINGS.md`：分镜时间轴和生成参数。
