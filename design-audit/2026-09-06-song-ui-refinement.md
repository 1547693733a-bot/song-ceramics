# 宋瓷界面调性统一 · 2026-09-06

本次为本地实现，不发布线上版本。以素笺、墨色、细线和适当留白调整现有界面，不把现代功能图标冒充为历史纹样。

## 调整

- 八窑共用返回、关闭与声音图标，细线等粗，保留可辨认的功能形状、按钮名称、声音状态与 44px 触控区域。
- 场景按钮采用轻微圆角的墨色底与细边框，替换大圆形悬浮按钮；减少装饰性光晕和模糊。
- 知识入口统一为空心小菱形配短题，不再使用数字圆圈与持续脉冲。不删除热点或修改对应器物位置。
- 章节使用中文序数，统一标题、引句及器物信息的字号、字重、行距。
- 科普面板采用浅纸色与墨色文字，一题一段，保留关闭、拖动、滚动和焦点反馈。
- 中文字体打包为本地 Noto Serif SC 正常字重子集：734 个字符、144948 字节（约 142 KiB）。使用 font-display: swap，运行时不依赖外部字体服务。未覆盖的新增字符会走系统后备字体，需要同步更新子集。

字体来源：[Google Fonts / Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，许可为 SIL OFL 1.1，随包保留 `public/assets/fonts/OFL.txt`。

## 保持不变

已认可的背景、器物、火焰素材及其亮度/颜色/混合方式、视频和声音均保持不变；保留窑口边界切换、三幕循环与每次手势仅换一幕的控制器。未修改受保护的手机框架文件。

## 验证

TypeScript 与生产构建通过，28 个受保护文件完整性检查通过。37 项测试通过，覆盖内容、入口火焰一致性、单次滑动、三幕循环、播放恢复、站点打包与本次 UI/字体规则。构建后的三份字体和许可文件均存在。本地 5174 服务返回 HTTP 200。

滑动测试原先按两个函数之间的文本区间截取代码；新增图标函数后造成误截取，现改为 TypeScript AST 精确提取滑动控制器，原有交互断言均保留。
