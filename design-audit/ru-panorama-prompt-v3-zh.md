# 汝窑背景提示词 V3：釉内云层与蟹爪开片增强版

## 修正目标

旧背景的天青色、开片和釉层变化都过于平均，经过球面裁切、火焰遮挡及运行时暗化后，容易退化成普通的浅青色背景。本版用“釉内云层 + 中尺度蟹爪开片 + 连续细腻釉面”建立识别度，不再依赖几乎不可见的细纹，也不使用会被模型误解成浮雕或冰面的莲瓣边界。

## 完整生成提示词

```text
使用场景：宋瓷手机交互界面中的北宋汝窑球面全景背景。最终图像会映射到球面，以约占全图宽度 28%–35% 的窄视场放大观看，并被运行时压暗约 35%。

生成一张严格 2:1 横向全景母图，建议 4096 × 2048，近距离、近似正投影观察一整片已经高温烧成的汝窑天青釉陶瓷表面。画面不是完整器物、房间、山水、天空、洞穴或窑门。第一阶段优先保证材质与构图质量，不要求左右无缝。

画面的第一视觉层是清楚但温和的釉内云层。使用低饱和雨过天青、淡鸭蛋青、月白和冷灰青，在透明而乳浊的釉层内部形成不规则、宽阔、连续的深浅带与积釉晕层。每一处釉云宽约全图的 12%–22%，边界柔和、没有线框、没有实体高度；相邻区域保持约 8%–14% 的明度差，使它在手机暗化后仍能被看见。颜色变化来自釉层厚薄和乳浊度，不是天空、云雾、海水或渐变壁纸。

第二视觉层是稀疏、可辨认的蟹爪开片。全图安排约 5–7 条中尺度主开片，走势自然、不对称，由单线分叉成两到三个逐渐收细的分支；局部补充少量更细的发丝开片。所有开片位于釉层内部，线条极细、连续、边缘平滑，呈柔和冷灰绿，比周围釉色深约 10%–14%。禁止黑线、金线、白色描边、凸起裂纹、串珠状裂边和巨大多边形石板。

表面必须基本平整、连续、光滑、致密，呈烧成成熟的细腻玻化半光泽。允许非常微弱的陶瓷微观质感和少量深层釉中气泡，但不得形成表面砂粒、针孔或圆点。没有莲瓣浮雕、花纹边框、山峦起伏、波浪、褶皱或雕塑高度。

这是用于放大观看的全景材质。任意占全图宽度约 28%–35% 的竖向裁切中，都必须同时看到至少一处天青到月白的釉内云层变化，以及一条主开片分支或一组细开片。禁止出现宽度超过全图 12% 的纯色空白区。中央窑火入口区域约占全图宽度 12%–14%，可以较安静，但仍保留一条柔和的中型开片和一处可见釉云过渡。

采用来自左上方的单一、宽而柔和的低角度博物馆掠光。高光面积小、边缘柔和，只用于揭示釉层厚度和乳浊深度；画面全域清晰，无雾层遮挡、无强景深、无四周暗角。整体气质是雨过天青、温润含露、空灵克制，但材质层次必须足以承受球面裁切和暗化。

禁止：空白浅蓝渐变、普通墙纸、天空云层、雾、海水、水面、冰面、磨砂玻璃、玉石板、翡翠、大理石、石膏、水泥、混凝土、蓝色洞穴、山水、山脉、布料褶皱、厚浮雕、莲瓣浮雕、花卉纹样、巨大弧形边界、密集满屏开片、哥窑金丝铁线、官窑深色双层开片、纯黑裂缝、蜘蛛网、干裂泥土、串珠裂边、裂纹凸脊、表面砂粒、凹坑、针孔、橘皮釉、泡沫、湿塑料、大片镜面反光、局部虚焦、机械重复、完整器物、器沿、器足、窑门、中心洞口、人物、火焰、文字、Logo、水印、边框、UI。
```

## 接缝修复提示词

```text
以完成的 2:1 汝窑背景母图为唯一编辑对象。锁定中央 80%–84% 的釉色、釉内云层、开片位置、光线和清晰度完全不变，只编辑最左和最右各约 8%–10% 的窄条，使左右边缘自然无缝衔接。边缘只能延续已有的天青釉云和被裁切的细开片，不新增粗裂纹，不重画中央区域，不降低局部对比，不生成明显重复接缝。
```
