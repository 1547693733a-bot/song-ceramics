这不是一组“把所有要求塞进同一张图”的提示词。正确顺序是：先生成一张风格母图，再以它为参考，分别生成泥团与两只手的图层。这样最终的动画才会像同一个世界。

## Prompt 01｜风格母图：一抔泥成为器的起点

先生成这张，作为后面所有素材的统一参考。它不直接上线。

```text
请根据四张参考图，创作一张用于手机竖屏交互动效的“定心开器”视觉母图。

画面是纯黑的无边界空间。画面中央偏下，一团深褐色、颗粒粗粝、略带湿润光泽的真实陶土，正放在一只几乎看不见的陶轮中央。两只成年陶工的手从左右下方安静进入：左手贴住泥团外侧，负责托稳；右手的拇指从上方垂直压入泥团顶部中心，刚刚开出一个深而圆的小孔。泥团不是椭圆石头，而是正在旋转中被扶正的初始陶坯：底部稳、中心轴清晰、上部略收，仍然粗厚、尚未成为完整花瓶。

最重要的是“从泥团到容器”的瞬间：孔洞必须是真正进入泥体的内腔，孔口边缘有湿泥被手指压开的柔软厚度，孔内是全画面最深的黑。泥团内壁带有非常细微的螺旋拉坯痕；这些旋纹在画面边缘轻轻呼应磁州窑界面的黑白剔花与水墨旋涡，但绝不提前出现牡丹、完整纹样或成品瓷器。

视觉语言：真实陶土的触感 + 磁州窑白地黑彩的克制黑白关系。手是低饱和、沾有泥浆的真实手，不是动漫手，不是古装人物，不出现人脸。袖口若可见，只是一小段近墨色、无纹样的粗布。画面安静、神秘、朴拙、有制作中的力量，不要仙侠感，不要博物馆展柜感。

镜头：略高于陶轮的正面近景，泥团位于手机画面约 55% 高度，两只手只占下半部，不遮住泥团轮廓；竖版 9:16 构图；没有手机外框、没有文字、没有 UI。

避免：赛璐璐动漫、粉色皮肤、粗黑描边、捏橡皮泥的侧向夹取、完整梅瓶、牡丹图案、釉面、火焰、烟雾、现代陶艺工具、古装表演、神秘光束、霓虹、文字、标志、水印。
```

## Prompt 02｜泥团图层：定心完成

用途：动画的“手扶住泥、偏摆消失”状态。单独生成泥团，不要手。

```text
以参考图 1 的真实泥团材质为唯一材质依据，以 Prompt 01 的风格母图为构图和光线依据。只生成一个可单独叠加的“定心完成泥团”图层。

纯黑背景中，一团深褐色粗颗粒陶土放在正中心。它刚被陶工扶正：形体围绕垂直轴稳定，底部略宽，上部轻微收拢，像一团即将被拉坯的厚实泥柱。表面保留真实泥粒、细小孔隙、手工压实后的不规则和很淡的旋转纹；泥团不应像 3D 建模的完美圆柱，也不应像石头。

画面必须干净：没有手、没有陶轮机械、没有阴影、没有火、没有文字。泥团四周留出足够黑色空间，完整轮廓清晰，正方形构图，方便后续叠加两只手。

避免：开孔、瓶口、瓶颈、瓶肩、完整花瓶、装饰图案、釉面、塑料质感、强烈高光、卡通风、文字、水印。
```

## Prompt 03｜泥团图层：开孔与初始器壁

用途：动画最关键的“泥第一次成为容器”状态。必须在 Prompt 02 的图上做编辑，不要从零生成。

```text
以“定心完成泥团”图片为编辑对象，保持画面中的机位、泥团比例、泥料颗粒、光线方向、背景纯黑和外部轮廓全部不变。

只改变泥团顶部中心：让一只拇指刚刚在正中心开出一个真正的圆形内腔。孔必须向下深入泥体，能看见湿润、深暗的内壁；孔口厚实而柔软，有被手指向下压开后微微向外推开的痕迹。孔内壁出现极细、连续的螺旋拉坯纹。孔口周围只轻微起壁，刚刚有一点器物的内外关系，绝不能形成完整花瓶。

画面中不要出现手，手会作为独立图层叠加。不要改变泥团的整体高度，不要增加任何装饰，不要把孔做成陨石坑或通到底部的洞。

避免：浅表凹痕、横向捏痕、宽口碗、细长瓶颈、完整梅瓶、白色化妆土、黑彩花纹、釉面、火焰、文字、水印。
```

## Prompt 04｜左手图层：扶泥定心

用途：独立透明手部图层。生成后去绿幕，不要让模型同时画泥团。

```text
生成一只用于手机端陶艺动画的“左手扶泥”独立图层。

一只成年陶工的左手，从画面左下方自然伸向中心。手掌侧面和虎口形成柔和弧线，轻轻贴住一团看不见的泥坯外侧；手指略微弯曲、彼此清楚分开，姿势是“扶住并稳定旋转中的泥”，不是抓握、不是捏取、不是托举。手部比例克制，手腕处裁切，手指尖保留足够边距。

手是低饱和的真实手：肤色偏灰暖，指腹与指甲边缘沾有深褐湿泥，短而干净的指甲，皮肤能看见自然细纹。没有人脸，没有首饰，没有指甲油；如出现袖口，只保留一小段近黑色粗布袖口。

背景必须是完全均匀的纯 #00ff00，用于后期去背。背景没有阴影、没有渐变、没有地面、没有反光、没有任何物体。画面为正方形，手只占画面左下到中部，构图为后续与泥团叠加预留空间。

避免：动漫手、赛璐璐描边、高饱和粉色皮肤、OK 手势、侧向夹取、用力抓握、额外手指、手指粘连、畸形手腕、陶艺工具、文字、标志、水印。
```

## Prompt 05｜右手图层：拇指开孔

用途：独立透明手部图层。这个手势决定是否像“制作器物”，一定要清晰。

```text
生成一只用于手机端陶艺动画的“右手开孔”独立图层。

一只成年陶工的右手，从画面右下方安静进入。右手拇指明确、垂直地指向画面中心下方，正准备按入一团看不见的定心泥坯顶部；食指和中指自然张开，轻轻靠近外侧器壁以稳定泥坯，其余手指放松弯曲。这个姿势必须一眼看出是“从顶部开出器物内腔”，而不是捏合、抓取、OK 手势或指点。

手是低饱和的真实手：肤色偏灰暖，拇指指腹和食指边缘带少量深褐湿泥，短而干净的指甲，可见自然皮肤细纹。没有人脸、首饰、指甲油；若有袖口，只能是一小段近黑色无纹粗布。

背景必须是完全均匀的纯 #00ff00，用于后期去背。背景没有阴影、没有渐变、没有地面、没有反光、没有任何物体。画面为正方形，手从右下伸向中上区域，拇指、食指和中指完整可见，四周保留边距。

避免：横向夹捏、OK 手势、拳头、指点、动漫手、粗描边、额外手指、手指粘连、畸形手腕、工具、文字、标志、水印。
```

## Prompt 06｜孔内转场纹理

用途：让“开孔”自然过渡到磁州窑二级界面。不是一张新全景，而是一层局部过渡纹理。

```text
以项目当前磁州窑二级界面截图为黑白气质参考，生成一张用于全屏转场的“器物内腔旋纹”抽象纹理。

画面从中心开始，是一圈深褐色、潮湿、带颗粒感的陶器内壁。内壁上有真实拉坯留下的连续弧形螺旋纹，像镜头正在慢慢进入刚被拇指开出的器物内腔。旋纹向画面四周拉长、抽象，并逐渐变成磁州窑白地黑彩中那种有刀感、有水墨节奏的黑白曲线；颜色从深泥褐色缓慢过渡到暖象牙白、炭黑和少量灰。

中心必须保留深黑入口，整体是内敛、缓慢、沉静的旋转，而不是科幻隧道。正方形构图，适合从中心放大到全屏。

避免：银河、虫洞、宇宙、迷幻漩涡、霓虹、大理石、金属、完整花瓶、牡丹图案、书法文字、火焰、烟雾、文字、标志、水印。
```

## 后续每帧都要追加的“锁定句”

当你已经选定 Prompt 01 的母图后，每一次生成动作帧都在末尾加上这句：

```text
严格保持参考母图中的机位、构图、主体位置、尺度关系、光线方向、黑色空间比例、泥料颜色和整体气质；只改变本次提示中明确说明的动作，不新增人物、物体、纹样或故事。
```

## 生成顺序

1. 先生成 Prompt 01，选出一张真正和现有磁州窑界面协调的风格母图。
2. 以母图为参考，完成 Prompt 02、03 的泥团两个关键状态。
3. 再生成 Prompt 04、05 的左右手图层；合成时先对齐手指与泥团接触点，再做进入与退出动画。
4. 最后生成 Prompt 06；现有磁州窑全景仍然直接使用，不重新生成。
